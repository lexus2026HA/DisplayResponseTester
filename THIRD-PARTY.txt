Display Response Tester v1.2 uses third-party software.

The Windows x64 release contains Python 3.12.9, Qt 6.12.0, PySide6 and
Shiboken6 6.12.0, NumPy 2.5.5, pySerial 3.5 and the PyInstaller 6.22.3 bootloader.
See the licenses directory in the release bundle for the applicable texts.

libraries as separate files in _internal. Users may replace those libraries with
